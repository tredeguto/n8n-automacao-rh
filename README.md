Este projeto automatiza o fluxo ponta a ponta do processo seletivo de Recursos Humanos utilizando **n8n**, **Tally Forms**, **Google Sheets**, **Google Calendar**, **Gmail** e **Inteligência Artificial (OpenAI / LangChain)**.

A solução reduz drasticamente a carga operacional da equipe de RH ao realizar a triagem inicial automática dos candidatos, agendamento de entrevistas e envio de e-mails de acompanhamento, mantendo a flexibilidade necessária para revisão e intervenção humana.

---

## 🛠️ Tecnologias Utilizadas

* **[n8n](https://n8n.io/)**: Plataforma principal de orquestração de fluxos de trabalho.
* **[OpenAI / GPT-4o-mini](https://openai.com/)**: Análise preditiva, pontuação (*score*) e extração estruturada dos currículos.
* **[Google Sheets](https://workspace.google.com/products/sheets/)**: Banco de dados e controle centralizado do *status* das candidaturas.
* **[Google Calendar](https://workspace.google.com/products/calendar/)**: Agendamento automático das entrevistas com os candidatos selecionados.
* **[Gmail](https://workspace.google.com/products/gmail/)**: Comunicação automatizada via e-mails estilizados em HTML.
* **[Tally Forms](https://tally.so/)**: Captura inicial e recebimento dos formulários de inscrição.
